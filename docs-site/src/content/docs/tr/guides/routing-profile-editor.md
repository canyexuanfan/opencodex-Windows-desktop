## Genel Bakış

Yönlendirme Profili Düzenleyicisi (Routing Profile Editor), web kontrol paneli üzerinden sağlayıcı yönlendirmelerini, model eşlemelerini ve kombo yük dengeleme kurallarını görsel olarak yapılandırmanızı sağlar.

## Özellikler

- **Görsel Model Eşleme:** Hangi model isteklerinin hangi sağlayıcı uç noktasına gideceğini tek tıkla seçin.
- **Doğrulama ve Kuru Çalıştırma (Dry-run):** Değişiklikleri kaydetmeden önce yapılandırmanın geçerliliğini test edin.
- **Anında Uygulama:** Yapılandırma kaydedildiğinde proxy yeniden başlatmaya gerek kalmadan canlı oturumlara anında yansır.
- **Yönetim API Entegrasyonu:** Tüm profil değişiklikleri arka planda `/api/routing` yönetim uç noktası üzerinden güvenli şekilde yürütülür.
