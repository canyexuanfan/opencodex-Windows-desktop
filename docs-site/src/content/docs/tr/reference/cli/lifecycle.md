---
title: "CLI Referansı: Yaşam Döngüsü"
description: "ocx start, stop, restart, doctor ve servis yönetimi komut satırı referansı."
---

## Komutlar

```bash
ocx start          # Proxy'yi ön planda başlatır
ocx stop           # Proxy'yi durdurur ve temizler
ocx restart        # Proxy'yi yeniden başlatır
ocx doctor         # Sistem ve bellek durumunu denetler
```

## Servis Yönetimi

```bash
ocx service install
ocx service status
ocx service repair
ocx service uninstall
```
