## Genel Bakış

Sidecar mimarisi, yerel web araması veya görsel anlama yeteneği olmayan modellere hafif bir yardımcı model (`gpt-5.4-mini`) üzerinden bu yetenekleri kazandırır.

- **Web Arama Sidecar'ı:** Model bir web araması yapmak istediğinde arama sorgusunu çalıştırır ve sonuçları özetleyerek modele aktarır.
- **Görsel Sidecar'ı:** Görsel içeren mesajları analiz eder ve açıklayıcı metin içeriğini ana modele iletir.
