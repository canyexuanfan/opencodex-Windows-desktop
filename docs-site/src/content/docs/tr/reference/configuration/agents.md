## Ajan Yapılandırma Alanları

`~/.opencodex/config.json` içindeki `agents` nesnesi:

```json
{
  "agents": {
    "subagentModels": ["anthropic/claude-opus-4-8", "openai/gpt-5.6-sol"],
    "surface": "v2"
  }
}
```
